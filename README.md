### 软件架构​：

技术栈分层：采用 “前端交互层 - 后端逻辑层 - 数据存储层” 三层架构​
前端交互层：基于 IAPP（手机端开发工具）+ HTML 构建，适配移动端操作场景，保障图片上传、管理的便捷性，支持多设备访问兼容​
后端逻辑层：以 PHP7.2 作为开发语言，通过模块化 API 实现业务逻辑（如用户认证、图片处理、会员管理等），执行效率高、扩展灵活​
数据存储层：使用 MySQL 数据库，存储用户信息、图片元数据（路径、加密状态等）、会员记录、统计数据等，保障数据安全性与可追溯性​
核心模块划分：用户管理模块、图片处理模块、会员充值模块、数据统计模块、广告配置模块，各模块通过独立 API 接口通信，低耦合易维护​
依赖说明：需服务器支持 PHP7.2 及以上版本，MySQL 5.6+ 数据库，无需额外依赖复杂框架，轻量化部署即可运行​

### 安装教程​：

环境准备：搭建 PHP7.2+ 运行环境（推荐搭配 Nginx/Apache 服务器），创建 MySQL 数据库（建议单独创建数据库用于存储系统数据，避免与其他项目混用）​
文件部署：将系统前端文件（IAPP 编译包 / HTML 页面）、后端 API 文件（如 upload.php、tongji.php 等）上传至服务器对应目录，确保 PHP 文件拥有可执行权限，前端文件路径与后端 API 接口地址匹配​
数据库配置：在后端核心配置文件（需自行确认或基于现有代码补充，如 config.php）中，填写 MySQL 数据库地址、用户名、密码、数据库名，确保后端能正常连接数据库；执行数据库初始化 SQL（需基于系统表结构手动创建，包含用户表、图片表、会员表、卡密表等），完成数据结构搭建​
功能测试：访问系统前端页面或演示地址，尝试注册账号、上传图片、发起充值等操作，检查功能是否正常运行，数据是否能正确写入数据库，若出现接口报错，可通过服务器日志排查 PHP 执行或数据库连接问题​

### 使用说明​：

用户操作指南​
注册登录：通过前端注册入口填写账号信息完成注册，使用注册账号登录系统，首次登录建议先完善个人头像（通过 “个人中心 - 上传头像” 功能）​
图片管理：登录后进入 “图片管理” 页面，可创建文件夹分类存储图片，点击 “上传图片” 选择本地图片，上传完成后可获取图片链接，支持设置卡密加密（点击 “加密” 输入密码生成加密链接）​
会员与充值：进入 “充值中心”，选择充值金额完成余额充值；在 “会员兑换” 页面输入会员卡密，点击兑换开通会员权益；每日可通过 “签到” 功能获取额外奖励（如余额、积分，具体奖励需数据库配置）​
数据查看：在 “数据统计” 页面，可查看个人上传图片总数、存储空间占用、近期上传趋势（折线图展示），清晰了解个人使用情况​
管理员操作（无可视化后端）：若需修改系统基础配置（如广告内容、签到奖励、会员权益），需通过 MySQL 数据库管理工具（如 Navicat）连接数据库，直接修改对应数据表字段（如广告内容修改 guanggao 表，签到奖励修改 qian 表）；如需删除违规用户或图片，直接删除 user 表或 tupian 表中对应数据​
二开建议：可基于现有 API 接口开发可视化后端管理界面（如使用 Vue+Element UI 构建），实现配置修改、数据管理的可视化操作；也可扩展功能，如增加图片压缩、多格式支持、批量上传等，需注意保持与原有技术栈的兼容性
